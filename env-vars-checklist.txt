Cloudflare Worker Env Vars — Paragraph Checker (Azure variant)
===============================================================

Where: dash.cloudflare.com -> your worker -> Settings -> Variables and Secrets
Tip:   Click "Edit" (next to "+ Add") to set multiple at once.

Name                    Type      Notes
----------------------  --------  ------------------------------------------------
AZURE_OPENAI_KEY        Secret    Azure portal -> your resource -> Keys and Endpoint
AZURE_ENDPOINT          Text      https://<your-resource>.openai.azure.com
AZURE_DEPLOYMENT_NAME   Text      e.g. gpt-4.1-mini (deployment name in Azure Studio)
AZURE_API_VERSION       Text      optional, defaults to 2024-10-21
ALLOWED_ORIGIN          Text      recommended: https://<your-github-username>.github.io
                                  (comma-separate several; unset = any site can call it)

NOT used any more (removed on purpose, student text is never logged):
  QUALTRICS_*, SYLLABUS_URL, COURSE_PAGE_URL

After deploying:
  1. Set WORKER_URL near the top of the <script> in index.html.
  2. Set the iframe src in brightspace.html to your GitHub Pages URL.
